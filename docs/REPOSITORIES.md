# 졸업 프로젝트 저장소 안내

같은 개인 졸업 프로젝트를 모델·통합 앱·분리 앱 저장소에서 다루고 있습니다. 파일이 겹치더라도 현재 브랜치별 코드가 완전히 같은 것은 아닙니다.

| 저장소 | 포함 범위 |
| --- | --- |
| [FYP](https://github.com/Skullking2520/FYP) | 공개 대표 저장소: 모델 실험·백엔드·웹 화면 |
| FYP_ui-backend | 통합 앱 작업 이력, 현재 비공개 |
| FYP_BACKEND | 분리 백엔드, 현재 비공개 |
| FYP_UI | 분리 프론트엔드, 현재 비공개 |

처음 보는 경우 공개 대표 저장소에서 시작합니다. 비공개 저장소를 읽을 권한이 있어야 분리 앱의 소스에 접근할 수 있습니다. 학습 실험과 실제 추천 API의 호출 경로는 구분합니다.
