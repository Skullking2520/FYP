# Model and reference assets

This directory contains recommendation artifacts and reference tables used by the backend. Loading a pickle executes Python object deserialization: use only trusted artifacts. Repository inspection checked file structure and hashes, without running model deserialization or training.

Some reference tables derive from the European Commission ESCO classification. This service uses the ESCO classification of the European Commission. The original download release and any transformations are not fully recorded here. See the [ESCO reuse conditions](https://esco.ec.europa.eu/en/about-esco/faq?page=1); this note does not grant rights to unrelated datasets.
